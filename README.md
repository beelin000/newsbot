# newsbot

Workspace for the Cursor Automation **newsbot agent**.

Twice daily (07:00 / 19:00, Asia/Shanghai) it collects major worldwide news in finance, technology, politics, and military affairs, then writes a Chinese briefing as Markdown and PDF.

Generated files:

- `newsletters/全球要闻简报-YYYY-MM-DD-上午.md` / `.pdf`
- `newsletters/全球要闻简报-YYYY-MM-DD-晚上.md` / `.pdf`

Download them from the Cloud Agent run, or pull this repo if a PR was opened.
